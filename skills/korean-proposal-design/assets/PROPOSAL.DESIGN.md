> Claude Design(claude.ai/design)에 **그대로 붙여넣어** 사용하는 디자인 시스템 파일입니다.
> "AI가 만든 티"(문단 간격 틀어짐, 템플릿 드리프트, 도형 정렬 오류)를 구조적으로 제거하도록 설계했습니다.
> `{{ }}` 로 표시된 부분(폰트·브랜드 색·레퍼런스 제안서)은 **사용자가 직접 채워 넣으세요.**

## 0. 사용법 (How to feed this into Claude Design)

1. Claude Design 새 프로젝트를 만들고, 첫 메시지에 **이 파일 전체를 붙여넣습니다.**
2. `{{FONT}}`, `{{BRAND_COLORS}}`, `{{REFERENCE_PROPOSAL}}` 을 실제 값으로 교체합니다.
3. 이어서 "이 DESIGN.md 규칙을 **엄격히** 지켜 제안서 표지/목차/본문/도표 페이지를 만들어줘" 라고 지시합니다.
4. 수정은 새 프롬프트로 다시 만들지 말고 **Tweaks(부분 수정)** 로 반복하세요. (재생성할수록 규칙이 흐트러집니다.)

## 2. 타이포그래피 (한글 특화 — 문단 간격 틀어짐 방지의 핵심)

- **글꼴(최대 2종):** 본문 `{{FONT — 예: Pretendard}}`, 제목 `{{FONT_HEADING — 예: Pretendard SemiBold 또는 나눔스퀘어}}`.
  - 한글 웹폰트 권장: **Pretendard**(가변, 한글 최적), Noto Sans KR, 나눔스퀘어. (라이선스 확인 후 사용자가 삽입)
- **한글 줄바꿈(중요):** 모든 본문 컨테이너에 `word-break: keep-all;` 를 적용한다.
  → 한글 단어가 어절 중간에서 끊기는 "AI 티"를 없앤다.
- **행간(line-height):** 한글 본문은 **1.6–1.75**. (라틴 기준 1.4–1.6보다 높게 — 한글은 글자 높이가 커서 좁으면 답답)
- **자간(letter-spacing):** 한글 본문 `-0.01em ~ -0.02em`, 큰 제목 `-0.02em ~ -0.03em`. (한글은 살짝 조여야 정돈됨)
- **본문 크기:** 최소 14px(권장 15–16px), 캡션 12px 이상. 한 줄 길이 **한글 35–45자 / 라틴 60–80자**.
- **위계:** 크기·굵기·색 중 **의미 있는 차이**로만 구분. 미세한 차이(2px)로 위계 흉내 내지 말 것.
  - 예시 스케일: `H1 32 / H2 24 / H3 18 / Body 15 / Caption 12` (아래 §3 스케일과 정렬).

## 3. 간격 시스템 (8pt 그리드 — "문단 간격 틀어짐" 근본 해결)

> **모든 여백·간격은 아래 토큰에서만 고른다. 임의값(예: 7px, 13px, 23px) 금지.**
> AI가 문단마다 제각각 margin을 넣어 간격이 틀어지는 문제를 스케일 강제로 차단한다.

```
--space-1: 4px    --space-2: 8px    --space-3: 12px   --space-4: 16px
--space-5: 24px   --space-6: 32px   --space-7: 48px   --space-8: 64px
```

- **문단(paragraph) 간 간격:** `--space-4`(16px)로 **전부 통일**. 문단마다 다른 값 절대 금지.
- **문단 내부:** `margin: 0;` + 부모의 `gap`으로만 간격 제어(양쪽 margin 상쇄 버그 예방).
- **섹션 간 간격:** `--space-7`(48px) 또는 `--space-8`(64px)로 통일.
- **카드/컨테이너 패딩:** 네 방향 동일값(예: 24px 24px 24px 24px). 상하좌우 제각각 금지.
- **콘텐츠 좌우 마진:** 전 페이지에서 **동일**. 페이지마다 흔들리면 "템플릿 드리프트"로 읽힌다.

---

## 4. 레이아웃 그리드 (템플릿 일관성 — 페이지마다 흔들림 방지)

- **12컬럼 그리드**, 거터 24px, 좌우 마진 고정.
- **표지 → 목차 → 간지 → 본문 → 도표 → 마무리** 페이지 타입을 정의하고, **같은 타입은 같은 마스터**를 재사용.
  (Claude에게 "각 페이지 타입의 마스터를 먼저 정하고, 이후 페이지는 그 마스터를 복제해 내용만 교체하라"고 지시.)
- **베이스라인 정렬:** 제목·본문·번호가 공통 베이스라인/좌측 정렬선에 붙는다. 좌/가운데 정렬 혼용 금지.
- **페이지 번호·러닝헤더:** 동일 위치·동일 스타일로 전 페이지 반복.

## 5. 도형·정렬·모서리 (도형 오류 방지)

- **모서리 반경(radius)은 고정 세트에서만:** `4 / 8 / 12 / 16 / 24px / full`. 임의값(7px, 11px) 금지.
  - **중첩 규칙:** 안쪽 요소가 바깥 요소 안에 있으면 `바깥 radius = 안쪽 radius + 패딩`.
  - 큰 요소일수록 큰 radius. 알약(pill)은 height의 50% 이상일 때만 의도적으로 사용.
- **정렬:** 모든 요소는 공유하는 모서리 또는 중심선에 정렬. 아이콘+텍스트는 **광학 정렬**(바운딩박스 아님).
- **겹침·충돌 금지:** 요소 간 겹침, z-index 꼬임, 도형 위 텍스트 넘침을 검수. (§7 체크리스트로 확인)
- **선(rule):** 구분선은 **헤어라인(1px, 저채도 회색)** 하나의 스타일로 통일. 두께 남발 금지.
- **그림자(elevation):** 3단계 이하 고정 스케일. 카드마다 다른 그림자 금지.
- **아이콘:** 한 가족만 사용(예: Phosphor 또는 Heroicons). 광학 사이즈 16/20/24/32px. 이모지 불릿 금지.

## 6. AI-Slop 지문 배제 (반드시 지킬 금지 목록)

| AI 티(fingerprint) | 대체 규칙 |
|---|---|
| teal `#16d5e6` 등 기본 액센트 남발 | `{{BRAND_COLORS}}` 액센트 1개만, 의미 있는 곳에만 |
| 우상단 깜빡이는 상태 점 | 애니메이션 상태 표시 금지 |
| 컨테이너 24/24/24 무한 중첩 | 중첩 최대 2단계 |
| 둥근카드 + 왼쪽 컬러바 | 한 가지 의미 역할에만 제한 |
| 3열 히어로 피처 그리드 | 교차행/단일열/마퀴 등 대안 사용 |
| 그라디언트 오브 / CSS 실루엣 목업 | 실제 콘텐츠·도표 사용, 장식 오브 금지 |
| 이모지 섹션 마커·불릿 | 번호·헤어라인·타입 위계로 구분 |
| 가운데 정렬 전면 사용 | 좌측 정렬 기본, 중앙은 표지 등 예외만 |

## 7. 출고 전 자동 검수 체크리스트 (Claude에게 "완성 후 이 목록을 스스로 점검하라")

- [ ] 모든 문단 간격이 16px로 동일한가? (제각각 margin 없는가)
- [ ] 모든 간격·패딩이 §3 토큰(4/8/12/16/24/32/48/64) 값인가? 임의값 0건인가?
- [ ] 좌우 콘텐츠 마진이 전 페이지 동일한가?
- [ ] 같은 페이지 타입은 같은 마스터를 재사용했는가?
- [ ] radius가 고정 세트(4/8/12/16/24/full)만 사용됐는가?
- [ ] 겹침·넘침·정렬 어긋남·잘린 도형이 없는가?
- [ ] 글꼴 2종 이하, 한글에 `word-break: keep-all` 적용됐는가?
- [ ] §6 금지 목록에 해당하는 요소가 하나도 없는가?
- [ ] 색 대비 WCAG AA(본문 4.5:1) 이상인가?

{{REFERENCE_PROPOSAL}} = 우수제안서 파일/링크, 브랜드 가이드 (직접 삽입)
